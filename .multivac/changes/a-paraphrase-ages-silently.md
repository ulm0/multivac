# A paraphrase ages silently

The project's own philosophy page names this failure, and the corpus commits it
once per amendment. MV-104 amended MV-02 honestly — three runtime dependencies,
dated, with the reason — and the retired sentence survives verbatim in six
places nobody looked at:

- `.specify/memory/constitution.md` Principle IV — *the runtime dependency
  count is two* — while the same document's Sync Impact Report says the
  principles are unchanged and in force. The Engineering Constraints section
  WAS amended. One document, two answers.
- MV-85's body: *the law pins two runtime dependencies*.
- MV-86's body: *a third runtime dependency the law calls a design change*.
- `CONTRIBUTING.md`, `configuration.md`, and the header of the test whose whole
  job is to have teeth about the number.

Five more rows say something the code no longer does: MV-68 still claims a tag
runs publish *and nothing else* while MV-77 made pages run on tags too — and
MV-68's own `count=2` leg PINS the false sentence into the CI file. MV-84's
bolded headline states the rule its own body repealed. MV-82 counts five
positive legs while carrying six. MV-31 promises the reference documents the
whole surface and checks a frozen nine-command, eleven-key list. MV-01's
no-network tombstone covers three files while the commands it is about import
five uncovered directories.

And the layer that reaches agents: the projected skill teaches an arrow-edge
`landing_order` the parser refuses, tells the interview to write its output
INTO the managed block `doors` regenerates, and claims `change apply`
re-projects doors — a mechanism that does not exist. `DESIGN.md` names
`targets.yml` as the shipped registry six times; the file has never existed
under that name.

The fix is the tool's own device, and MV-111 makes it mechanical: an amendment
that kills a sentence ships an `absent` leg on the retired phrase, so the sixth
copy is a red rather than a discovery two audits later.

Out of scope, deliberately: the Claude harness hook still exits 1 with its
findings on stdout, and Claude Code only feeds exit-2 stderr back to the model,
so a red verify reaches nobody. Fixing it means BLOCKING the agent's edit,
which is a policy decision about somebody else's working session — stated here
with the exact change, not taken.
