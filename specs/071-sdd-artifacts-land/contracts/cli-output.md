# Contract: what the commands print

## change close

| condition | line |
| --- | --- |
| SDD artifacts for the slug were found in the brain | the printed `git add --` pathspec includes each of them, after the change file and the law |
| a dirty tracked file of the SDD's that the run did not write | `sdd <name>: <path> is dirty and was not staged — it is not this change's to commit` |
| no SDD declared, `sdd_auto: false`, or `--no-sdd` | the pathspec is unchanged from today |

## change apply

Order of the printed lines is the order of the work: a clone or a greenfield
line, then equip's lines for that repo, then the branch and carry lines. No new
line is introduced.

## The code gate

A path under a directory a declared integration writes is not code. Nothing is
printed for it: it simply does not appear in the `code` line's count.
