behaviour"); the docs half is checked by its legs, each dry-run on the tree it lands on. Work in
the change's worktree, `.multivac/worktrees/skill-cites-references/brain`.

This change lands after graph-answers-where-asked (#5), codegraph-worktrees-and-verbs (#6),
change-file-cites (#7) and verify-rooted-and-quiet (#8), each of which edits the skill and the
docs. **Every byte figure, leg count and `file:line` in these tasks is the design's, measured on
`62d4588`, and is re-measured by Phase 1 on the merged tree before any edit; the trimmed pack is
RE-DERIVED there with the design's classification method (said elsewhere / only here / false),
never copied from the design's prototype, and every fact #5–#8 put into the skill that no
command prints on the merged tree is kept.** Where a merged line moved, the task follows the
text, not the number.

Rules for every task: a task that rewrites a file keeps every existing leg on that file at its
count, and a leg it makes false is moved in `.multivac/invariants.md` by that same task (none is
expected: research.md R11); each new MV-152 leg is added by the task whose edit turns it green,
never before (FR-028), and is dry-run with `mvac count` there; no test title an existing leg
reads is changed; site pages name no law ID and no version string (MV-126, MV-84), and every
site edit is dry-run against those two legs; `.claude/skills/multivac/**`, `AGENTS.md`,
`CLAUDE.md`, `.multivac/flow.md` and `.multivac/ecosystem.json` are regenerated by `multivac
doors`, never hand-edited.
