# Phase 1 — Data model: A paraphrase ages silently

## A rule, and its copies

| Kind | Anchored? | May state a rule? |
| --- | --- | --- |
| the row in `.multivac/invariants.md` | yes | yes — this is where a rule lives |
| a row's amendment note | yes, by the row | yes, including quoting what it retired |
| the constitution | no | yes, and it is amended in the same change |
| a doc page, a test title, another row's body | no | **cite the ID, do not restate** |

## Retirement, as a state change

| Clause state | Written as | Anchored by |
| --- | --- | --- |
| in force | the row's sentence | the row's legs |
| retired | the same sentence, marked WITHDRAWN with the reason and the row that superseded it | a leg that does NOT pin the retired words |
| retired **and** guarded | the above, plus an `absent` leg on the retired phrase | that leg |

The third state is what MV-111 adds. The `absent` leg is scoped to exclude the
amendment note itself, so history stays writable.
