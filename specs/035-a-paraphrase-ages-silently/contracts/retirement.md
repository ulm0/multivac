# Contract — how a sentence is retired

## When a rule changes

1. The row is amended in place, dated, naming the row that supersedes it.
2. Every unanchored restatement is corrected in the same change — the
   constitution, `CONTRIBUTING.md`, the site, another row's body, a test title.
3. The amendment ships an `absent` leg on the retired phrase, excluding the
   amendment note that quotes it.
4. From then on, the sixth copy is a red, not an audit finding.

## What may restate a rule

| Artifact | May restate | Must cite |
| --- | --- | --- |
| the row | yes | — |
| the constitution | yes | the row |
| a doc page | prefer citing | the row |
| another row's body | no | the row |
| a test | no | the row |

## What the tombstone may not do

It may not make history unwritable. A retired sentence quoted inside a recorded
amendment is the sanctioned exception, and the leg excludes it explicitly.
